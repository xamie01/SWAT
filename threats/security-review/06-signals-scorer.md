**Entrypoint/cron/queue/subscriber map — source wiring only.** Signal engine creates alert/per-chain trade queues, starts an immediate tick and a 15-second timer, and subscribes/resubscribes to `walletSwap`; each tick isolates detector promises, with a process-local overlap guard (/home/xahmie/Documents/SWAT/apps/signal-engine/src/index.ts:79-125,670-724). Scorer schedules the nightly batch at **02:00 UTC**, MTM/stop-loss/close-all every **five minutes**, and receives `clusterRefresh`/`scorerRun`; optional `RUN_ON_STARTUP` invokes the batch (/home/xahmie/Documents/SWAT/apps/scorer/src/index.ts:195-264,300-344). Exit producers add per-chain jobs with four attempts and exponential backoff (/home/xahmie/Documents/SWAT/apps/scorer/src/index.ts:202-212,244-252). Discovery schedules **02:30 UTC**, subscribes to `discoveryRun`, optionally runs on startup, and enqueues wallet backfills after upsert (/home/xahmie/Documents/SWAT/apps/discovery/src/index.ts:24-87). Executor's direct-main guard starts per-chain/drain workers; failures are logged, reconciliation/order polling run every minute (/home/xahmie/Documents/SWAT/apps/trade-executor/src/index.ts:2893-2931). No HTTP webhook is defined in these reviewed service entrypoints; indexer HTTP wiring is covered in report 05. Installed service multiplicity and Redis access controls are NOT VERIFIED.

### Numbered remediation and neighboring compatibility

1. **SIG-01: preserve tenancy at every layer.** Producer job IDs already distinguish users; repairing only queue identity cannot fix downstream claims. Make tenant input mandatory for user jobs, including shadow execution and trade records, and reject canonical rows belonging to another principal. DB uniqueness already includes tenant, but the current caller defaults to null; trade values likewise normalize an omitted user to null (/home/xahmie/Documents/SWAT/apps/signal-engine/src/fanout-enqueue.ts:242-255; /home/xahmie/Documents/SWAT/packages/db/src/copy-trade-lifecycle.ts:1770,1840-1842; /home/xahmie/Documents/SWAT/packages/db/src/trades.ts:179). Preserve explicit legacy-operator compatibility, not implicit fallback. Fanout also carries executionMode/mirrors, while worker independently resolves mode; reconcile the permitted mode with current platform restrictions rather than trusting stale payload or silently widening it (/home/xahmie/Documents/SWAT/apps/signal-engine/src/fanout-enqueue.ts:249-252; /home/xahmie/Documents/SWAT/apps/trade-executor/src/index.ts:1462-1469).
2. **SIG-02: repair the actual claim, not the neighboring API.** A different request path already caps against master lots, but the source-signal claim used by the worker does not (/home/xahmie/Documents/SWAT/packages/db/src/copy-trade-lifecycle.ts:1546-1579,1952-1976). Reserve owned lots and aggregate balance under compatible locks; apply the source fraction to the master's available quantity. Fill allocation already limits reductions to that master and throws on excess, which protects bookkeeping too late to prevent an external over-sale (/home/xahmie/Documents/SWAT/packages/db/src/copy-trade-lifecycle.ts:2332-2365; /home/xahmie/Documents/SWAT/packages/db/src/lot-allocation.ts:68-73). Reconcile historical venue/lot divergence explicitly. This implements the ADR's contract, not proof that the accepted ADR is already operational (/home/xahmie/Documents/SWAT/docs/adr/0007-master-attributed-inventory.md:53-69,139-158).
3. **SIG-03/04: unify exit execution contracts.** Reuse tenant-owned lot-exit claims, and carry execution ID, scope, exact decimal quantity, acquisition mode and settlement account. Close-all's paper fallback loads its execution only after the blocking pending-signal branch; merely adding `closeAll` to the exemption is insufficient for live adapters (/home/xahmie/Documents/SWAT/apps/trade-executor/src/index.ts:1683-1688,2434-2435,2309-2311). Stop-loss paper sizing does preserve the supplied quantity, but it does not construct canonical lot evidence, and producer claims never reserve lot inventory (/home/xahmie/Documents/SWAT/apps/trade-executor/src/index.ts:2454-2458,2582-2620; /home/xahmie/Documents/SWAT/packages/db/src/stop-loss.ts:85-107). Exit failures require stateful retry/release after proving no submission, not deleting guards indiscriminately.
4. **SIG-05: make reducing sells independently admissible.** Capacity already deliberately bypasses sells; extend direction-aware policy to entry score, purchase balance and position count, without bypassing intentional kill switches, authority or physical inventory (/home/xahmie/Documents/SWAT/apps/signal-engine/src/index.ts:274-283; /home/xahmie/Documents/SWAT/packages/db/src/fanout-eligibility.ts:233-263). Paused/low-scoring sources need an owned-lot exit path rather than the active-wallet candidate filter. Explicit user opt-outs need documented semantics; this finding does not recommend executing through an explicit kill.
5. **SIG-06/07: distinguish qualification, control and opportunity.** Discovery's funded/co-buy SQL identifies candidates, not actual trade counterparties or beneficial ownership (/home/xahmie/Documents/SWAT/packages/db/src/discovery-queries.ts:29-67). Genuine masters also create predictable follower cohorts without fake performance: capacity and exits must contain that separate market-impact exposure (/home/xahmie/Documents/SWAT/packages/db/src/master-capacity.ts:731-780). Out-of-sample metrics correctly exclude pre-observation/open/incomplete episodes and expose insufficient history, but the production caller supplies no persistence hook and only logs reports; it does not replace the legacy score gate (/home/xahmie/Documents/SWAT/apps/scorer/src/master-metrics.ts:178-285,593-609,683,759; /home/xahmie/Documents/SWAT/apps/scorer/src/index.ts:159-175). Its query forces fees NULL despite migration 062 adding a fee column; keep gross/net labels honest and wire measured fee availability, not guessed zeros (/home/xahmie/Documents/SWAT/apps/scorer/src/master-metrics.ts:852-884; /home/xahmie/Documents/SWAT/packages/db/sql/062_source_trade_fees.sql:4-5).
6. **SIG-08/09: treat capacity and delivery as durable accounting.** Fully unknown primary capacity fails closed at the actual fanout caller; partial-unpriced coverage can still admit. Do not describe all uncertainty as fail-open (/home/xahmie/Documents/SWAT/apps/signal-engine/src/capacity-inputs.ts:655; /home/xahmie/Documents/SWAT/packages/db/src/master-capacity.ts:721-747,815-839). AMM usable depth is TVL/2 marked approximate, not measured concentrated-liquidity depth; Polygon uses its separate book path (/home/xahmie/Documents/SWAT/packages/db/src/master-capacity.ts:174-198,217-222; /home/xahmie/Documents/SWAT/apps/signal-engine/src/capacity-inputs.ts:619-653). Persist obligations before work can disappear and alert on missing accrual. Queue-add exceptions do propagate and polling can retry undispatched sources; contrast that with enumeration-null success and later worker failure (/home/xahmie/Documents/SWAT/apps/signal-engine/src/fanout-enqueue.ts:349-359; /home/xahmie/Documents/SWAT/packages/db/src/copy-trade-lifecycle.ts:874-877; /home/xahmie/Documents/SWAT/apps/signal-engine/src/index.ts:306-313,586-587).

That policy has its own ceiling configuration, not the shared variable, and samples time before the awaited market-state read (/home/xahmie/Documents/SWAT/apps/trade-executor/src/polymarket-staleness.ts:337-355; /home/xahmie/Documents/SWAT/apps/trade-executor/src/polymarket.ts:797-800).
