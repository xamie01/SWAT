## Trust boundaries

- Session token to process-local identity cache to authenticated API: revocation must remain authoritative across concurrent resolutions and processes.
- Session-derived tenant scope to SQL: explicit predicates and actual database role/transaction settings must both enforce the intended isolation; role existence is not pool identity.
- External transaction/market metadata to canonical source trade and follower signals: successful execution, wallet-attributable swap provenance, exact asset quantities and evidence quality must precede copying.
- Test configuration to database/Redis administration: a database name ending in `_test` is not authorization to terminate unrelated connections.
- Symmetric custody wrapping in the API: process compromise is inside the wrapping/unwrapping authority boundary, even if browser responses omit the ciphertext and root key.
